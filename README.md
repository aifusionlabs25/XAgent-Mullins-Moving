# Evan Mullins Moving Screening Room

Standalone private screening-room site for the Evan X Agent concept prepared for Mullins Moving.

## Local Preview

Open `index.html` directly in a browser, or serve this folder with any static file server.

## Deployment

This project is static HTML/CSS and can be deployed on Vercel, Netlify, GitHub Pages, or any static host.

The live demo button currently links to:

`https://xagent.aifusionlabs.app/demo/evan`
